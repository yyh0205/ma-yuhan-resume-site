# 马宇涵｜个人履历网站

这是一个无需安装依赖的静态网站。直接双击 `index.html` 即可在浏览器打开；如需上线，可将整个文件夹部署到任意静态托管服务。

## 文件说明

- `index.html`：网站内容与页面结构
- `styles.css`：视觉与响应式样式
- `app.js`：经历筛选、复制联系方式、导航状态与打印功能

## 使用建议

页面右上角的“打印 / 导出”会打开浏览器打印窗口，可选择“另存为 PDF”。

已加入：

- GitHub：`https://github.com/yyh0205`
- 项目合集：`https://yyh0205.github.io/intern-projects/`
- 小红书面经分享：`https://www.xiaohongshu.com/user/profile/64833266000000001f006155`
- 原版简历：`assets/ma-yuhan-resume-original.jpg`，首页可直接在新标签查看。
- 个人照片：首屏头像使用 `assets/portrait-city.jpg`，页面后段照片使用 `assets/portrait-hero.jpg`。

当前页面也可通过浏览器“打印 / 导出”另存为网站版 PDF。

网站中的量化成果按所属实习项目分别展示，没有将不同口径的数据合并计算。
